# G04 inactive CI previews

These templates are review-only and deliberately outside `.github/workflows`. They require pre-provisioned dependencies and immutable release ZIPs. They do not install packages, upload cloud artifacts, access real product data, enable affiliate links or deploy anything.

`baseline-defects` is evidence that the known A07/B08 failures were reproduced; it is not a functional pass for the product contract. `canonical-fixed` is the required profile for future A08/B09.
