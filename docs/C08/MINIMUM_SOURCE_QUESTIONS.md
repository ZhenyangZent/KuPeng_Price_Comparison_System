# 真實來源授權所需最小問題

STATUS: `SOURCE_BLOCKED`

1. 資料由誰提供，是否明確授權此使用者取得、顯示及保存？文件 SHA、版本與有效期限為何？
2. product／SKU／seller／condition／package 如何精確對應？
3. coupon 是否已領取且對此 eligibility profile、時間窗及商品 scope 確認適用？
4. 券前價與券後價各自來源為何？是否已含券，如何防止二次折抵？
5. 價格與資格 metadata 可保存多久；撤銷、刪除、更正及重新展示條件為何？
6. 運費及必要費用是否已知？若未知，通知不得宣稱到手總價或免費。
7. 是否另有正式分潤 URL technical/account/runtime/redirect authority？沒有則 CTA 必須關閉。

這是一次性的最小 evidence gate，不授權自動聯絡、掃描網站或讀取帳號。
