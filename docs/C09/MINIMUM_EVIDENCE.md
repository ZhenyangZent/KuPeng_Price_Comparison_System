# 未來真實來源最低證據（尚未授權）

真實來源如要離開 `SOURCE_BLOCKED`，至少需另行提供且由中央批准：精確 source ID 與 source class、可驗證 proof locator 與來源 bytes SHA-256、蒐集／保存／展示／連結揭露四項分離權利、地域與用途 scope、有效期及撤銷狀態、精確 product/SKU/seller/condition/package 綁定，以及 coupon ID、適用資格、有效期和 eligibility evidence。

即使上述資料齊全，本輪 C09 仍不會自動批准；`USER_ENTERED`、`USER_FILE` 與 `LICENSED_SOURCE` 都維持拒絕，必須由新 authority 與新版本介面審核。不得將使用者提供資料等同於可公開展示、轉售或建立 affiliate link 的授權。
