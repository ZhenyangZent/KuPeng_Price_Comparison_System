STATUS: `SOURCE_BLOCKED`

不再重複搜尋既有授權論點。若使用者取得新材料，只需提交以下已脫敏、可雜湊版本：

1. 台灣官方文件身分、版本、生效／失效日與 Partners 適用範圍。
2. 優惠券價格與資格資料的合法取得方式；是否帳號限定、首購、WOW、私人券或需先領取。

4. 券前價、券後價、資格 metadata 的保存期限、重新展示、刪除／更正與歷史顯示權。
5. 若另含分潤 URL 轉換，需獨立 technical/account/runtime/exact-match/redirect authority；不能由 coupon 文件推定。
