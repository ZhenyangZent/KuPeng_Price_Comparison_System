# E23 公開 GitHub 上傳排除與限制

本機完整盤點為 105,526 個路徑（建立 Git 候選前的快照）。初篩有 1,183 個小型純文字候選；二次檢查排除 36 個，隔離候選保留 1,147 個來源檔，另產生三份公開用的去識別索引。此數字只是發布資格篩選，不代表正式產品驗收。

| 快取、依賴與建置物 | 51,522 | 不發布，原處保留。 |
| Review 證據／工作目錄 | 34,755 | 不直接發布，避免把未驗收、截圖或資料庫當安全內容。 |

GitHub 公開版 `PROJECT_FILE_INDEX.csv` 僅列實際進入公開候選的純文字檔；本機完整索引留在專案根目錄。公開版 `EXTERNAL_PATH_LEDGER.csv` 只說明本機有去識別台帳，不公開 Windows 絕對外部路徑。正式原件和 H13 失敗候選都沒有刪除或移動。

限制：規則式文字掃描無法證明所有二進位、影像或巢狀 ZIP 均無敏感資訊，因此本輪不發布任何歷史 release 資產。GitHub 正式同步與否以 `FINAL_SYNC_RESULT.json` 的遠端 SHA readback 為準。
