# F08 fail-closed CTA verification contract

F08 defines exact product, SKU, variant, seller and market intent fields for a future separately authorized Taiwan Partners capability review. It validates synthetic evidence time, revocation, attribution TTL, identity binding, exact ASCII host/path allowlists and candidate URL structure.

This release cannot activate a CTA. Coupon price, source permission, a product reference URL, or positive-looking contract fixtures never produce affiliate capability. Every decision returns `SOURCE_AUTHORIZATION_REQUIRED`, `cta_enabled=false`, and `click_url=null`.

Only `.invalid` synthetic hosts are accepted in contract fixtures. No HTTP client, environment loader, browser, live click, redirect following, deep-link generation, deployment, or shopping action exists.
